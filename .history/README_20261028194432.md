# hextail/core

Hextail's core: a self-hosted CMS for single-page apps, by [Wondermake](https://wondermake.xyz).

Every page is published three ways: semantic HTML for search engines, markdown for AI agents, and your app for people. Pages and queries are served as static files, from ordinary PHP hosting.

**Status:** in development. The first public release is planned for 2027. Until then, this package only holds the name, and can't be installed.
